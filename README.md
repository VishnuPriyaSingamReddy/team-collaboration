# Team Collaboration Using GitHub

## Objective
To understand team collaboration using GitHub.

## Tools Used
- Git
- GitHub
- Command Prompt
- HTML

## Tasks Performed
1. Created a shared GitHub repository.
2. Created a feature branch named `feature-homepage`.
3. Created an HTML homepage.
4. Added and committed files.
5. Pushed changes to GitHub.
6. Created a Pull Request.
7. Merged changes into the main branch.
8. Created GitHub Issues.
9. Documented the project using README.md.

## Result
Successfully performed team collaboration using GitHub by implementing branches, commits, pull requests, issue tracking and documentation.
